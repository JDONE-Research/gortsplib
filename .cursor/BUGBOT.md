# Bugbot 리뷰 지침 — gortsplib

저장소 규칙 전체는 루트 `AGENTS.md` 에 있다. 이 파일은 리뷰에 필요한 것만 추린다.

## 공통

- 지적 제목·설명·요약은 한국어로 쓴다. 코드·식별자·파일 경로는 원문 그대로 둔다.
- 실제로 잘못 동작하는 버그를 먼저 본다. 어떤 입력·상태에서 무엇이 틀리는지 재현 조건과 결과를 적는다.
- 스타일은 아래 「스타일 위반」에 해당할 때만 낮은 심각도로 지적한다. 취향 차이는 지적하지 않는다.
- PR 제목이 `<이모지> <타입>: <한국어 한 문장>` 형식(예: `🐞 Fix: …한다`)이 아니면 한 번 알린다.
- 커밋·PR 본문에 `Co-Authored-By:`·`Generated with …` 줄이 있으면 알린다.

## 이 저장소에서 특히 볼 것

- **RFC 7616/2617 준수**: qop 목록 파싱(따옴표·쉼표·공백), `auth-int` 만 줄 때의 처리, nonce 를 다시 쓸 때 `nc` 증가, cnonce 난수, opaque 인용, 알고리즘별 해시(MD5·SHA-256)
- 레거시 경로(qop 없음) 응답이 그대로인지, 서버 쪽 `Verify` 와 짝이 맞는지
- 헤더 Marshal/Unmarshal 대칭, 빈 값·nil 포인터 처리 (qop·nc·cnonce 는 지금 클라이언트 송신 쪽만 지원하는 것이 알려진 한계다)
- upstream 코드를 건드릴 때 Client·Server 내부 고루틴 동시성(race), 32비트 빌드
- upstream 공개 API·동작 변경과 불필요한 diff(주석 삭제·리포맷·이름 변경)
- 모듈 경로 변경 (쓰는 쪽 replace 가 깨진다)
